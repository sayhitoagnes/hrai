# Not in this build

These are deliberate scope choices, not unfinished bugs.

- Login, SSO, or role permissions
- Database or shared server storage (records stay in this browser, plus optional JSON file)
- Company mail server / Microsoft 365 sending (this build generates a one-time email and opens an Outlook draft; the staff link is opened in this browser)
- Live employee or asset-register data
- Certified digital signature (DocuSign, iAM Smart, certificate-backed signing)
- IT asset-management integration (serial inventory, MDM)
- Multi-language (English form text matches Form R1)
- Audit log beyond signature timestamps stored on the record
