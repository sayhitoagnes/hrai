# hrai

## Mid-Autumn staff activity

Hong Kong Arts Centre internal celebration: **The Viewing Room / 賞月室**.

Adult 燈謎 (verse, idiom, cryptic) plus one lantern inscription, modelled on how Hong Kong organisations still run online Mid-Autumn — not a carnival tap-game.
