## Mid-Autumn staff activity

Hong Kong Arts Centre internal celebration: **The Mooncake Puzzle / 月餅謎局 · 燈謎**.

A mooncake pair puzzle, a reunion table, six lantern riddles, and one inscription. The last page shows an accumulated score. There is no lucky draw. Nothing is emailed from the page.
